# Laboratorio 6 - Fundamentos de Programación
## Tema: Introducción a la programación modular y reutilización
### Integrante: [Fabrizio Ortega]
- Este archivo contiene mi parte del trabajo: 
1. Crear una carpeta de proyecto con un archivo principal (main.py o Program.cs) y otro
archivo adicional donde se definan las funciones reutilizables (utils.py o Funciones.cs)

2. Diseñar e implementar al menos tres funciones:
- Una función sin parámetros que muestre un mensaje de bienvenida.
- Una función con parámetros que reciba dos números y devuelva su suma o
promedio.
- Una función que valide si una cadena ingresada es un correo electrónico.
